# Banking System (Backend)

## 📌 Description

This is a simple backend project developed using **Java, JDBC, SQLite, and Maven**.
It performs basic database operations on employee records.

---

## 🚀 Features

* Insert employee details
* Update employee details
* Delete employee records
* Display all employees

---

## 🛠️ Technologies Used

* Java
* JDBC
* SQLite
* Maven

---

## ▶️ How to Run

1. Open the project in any Java IDE
2. Configure database path in `DBConnection.java`
3. Run `MainApp.java`

---

## 🗄️ Database Table

```sql
CREATE TABLE emp_master (
    empno INTEGER PRIMARY KEY,
    empname TEXT,
    address TEXT,
    city TEXT
);
```
